# Inventory Management Data Analysis Project
# Project Overview
This project demonstrates an end-to-end inventory data analysis workflow using MySQL, Excel, and Power BI. The goal was to simulate a real business scenario where inventory managers need to monitor stock movement, track product performance, and identify potential stock shortages.
The project focuses on transforming raw inventory data into actionable insights through data cleaning, analysis, and dashboard reporting.

#        Tools Used:
MySQL: Data cleaning and analytical queries.

Excel: Inventory management system and KPI dashboard.

Power BI: Interactive data visualisation and business insights.

This project reflects a typical workflow used by data analysts in supply chain and retail environments.

#      Business Problem
Inventory management is critical for businesses that rely on product availability. Poor inventory tracking can result in:

Overstocking, which increases storage costs.

Stock shortages, which lead to lost sales.

Lack of visibility into product performance.

# The objective of this project was to build a system capable of:
Tracking stock movement (Stock In / Stock Out).

Calculating real-time inventory balance.

Identifying products that require restocking.

Highlighting top-selling products.

Providing decision-making insights through dashboards.

Data Workflow
The project followed a structured data analysis workflow:

# 1   Data Preparation (MySQL)
Raw inventory data was imported into MySQL for cleaning and preparation.

Key steps included:

Removing duplicates

Standardising product naming

Validating product codes

Structuring tables for analysis

Preparing aggregated metrics for reporting

SQL queries were used to generate analytical datasets used in dashboards.

# 2️   Inventory Management System (Excel)
Excel was used to build a functional Inventory Management System capable of tracking product movement.

Features implemented:

Stock in the table for recording purchases.

Stock Out table for recording sales.

Automatic calculation of inventory balance.

Reorder alert system for low stock items.

KPI dashboard summarising inventory performance.

Key Metrics Displayed:
Total Products

Total Inventory Units

Items to Reorder

Out of Stock / Negative Stock

Top Selling Product

Excel formulas used include:
SUMIF

COUNTIF

INDEX + MATCH

Conditional formatting for stock alerts.

This system simulates a simplified inventory tracking tool used in small businesses.

# 3️    Data Visualisation (Power BI)
Power BI dashboards were created to analyse inventory patterns and support decision-making.

Visualisations include:

Inventory distribution by product category

Top-selling products

Stock movement trends

Inventory status indicators

Product performance comparison

These dashboards transform raw inventory data into clear, actionable insights for business stakeholders.

# Key Insights from the Analysis
Several business insights were identified during analysis:

Inventory Risk Monitoring.

The dashboard identifies products with low stock or negative stock levels, allowing managers to take proactive restocking actions.

Top Selling Products

High-demand products were identified through sales aggregation, helping businesses prioritise purchasing and stocking decisions.

Overstock vs Stock Shortage

The analysis highlights products with excessive inventory versus those at risk of stock-outs.

Inventory Visibility

The system provides a centralised view of inventory activity, improving operational awareness.
